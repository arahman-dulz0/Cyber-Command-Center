# Contributing to Cyber Command Center

Thanks for your interest in improving the project — bug reports, features, docs,
and plugins are all welcome.

The full contributing guide lives in **[docs/contributing.md](docs/contributing.md)**.
Quick pointers:

- **Bugs / features** — open a [GitHub issue](https://github.com/arahman-dulz0/Cyber-Command-Center/issues).
- **Pull requests** — keep them focused, match the existing style, reuse existing
  services, and make sure `cd website && npm run build` (and, for the bot,
  `python -m py_compile`) pass. **Never commit secrets** — `.env` is gitignored.
- **Plugins** — a new monitor, enrichment source, or analyst tool is a small,
  single-file extension. See **[docs/plugins.md](docs/plugins.md)**.
- **Local setup** — see the **[Developer Guide](docs/developer-guide.md)** and the
  **[Getting Started guide](docs/getting-started.md)**.
